## Rotation
In ThreeJS there will be only **Radian**.

So you need to convert <ins>**Degree → Radian**</ins>

<ins>Here is the formula</ins>

> 30° → 30° x π/180 = π/6

If you want to convert <ins>**Radian → Degree**</ins>

> π/2 → π/2 x 180/π = 90°
